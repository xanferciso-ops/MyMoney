Cara Mengunduh & Memasang JotCash

Ikuti 3 langkah mudah berikut untuk memasang aplikasi pada perangkat Android Anda.

1

Unduh JotCash.apk

Tekan tombol Download JotCash.apk di halaman ini dan tunggu hingga proses unduhan di peramban selesai.

2

Buka & Beri Izin

Ketuk berkas dari notifikasi atau folder Download. Jika diminta izin pemasangan luar Play Store, pilih Setelan lalu aktifkan izin.

3

Install & Gunakan

Tekan Install (atau Tetap install pada pemberitahuan Play Protect), lalu buka JotCash dari layar utama HP Anda.

Pertanyaan yang Sering Diajukan

Apakah data keuangan saya aman di JotCash? expand_more

Sangat aman. JotCash bekerja 100% secara offline dan menyimpan seluruh catatan langsung di penyimpanan internal HP Anda. Tidak ada data yang dikirim ke server luar mana pun.

Bagaimana agar data tidak hilang saat memperbarui aplikasi? expand_more

Sebelum menghapus aplikasi lama atau pindah ke HP baru, masuk ke menu Setelan → Backup Save Data untuk menyimpan berkas cadangan .json ke folder Download, lalu gunakan menu Pulihkan Save Data pada aplikasi baru.

Mengapa muncul peringatan saat memasang file APK? expand_more

Peringatan tersebut adalah prosedur standar Android untuk semua berkas APK yang diunduh langsung dari situs resmi di luar Google Play Store. Anda cukup mengizinkan pemasangan dari peramban untuk melanjutkan.
